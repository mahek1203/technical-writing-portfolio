# Online Examination System — User Guide

**Document Type:** User Guide  
**Version:** 1.0  
**Audience:** Students / Examination Candidates  
**Status:** Sample Technical Documentation

---

## 1. Introduction

The Online Examination System is a web-based platform that allows users to participate in examinations remotely. The system provides functionality for logging in, accessing assigned examinations, answering questions, submitting responses, and viewing examination results.

This user guide explains how to use the system and provides step-by-step instructions for completing an online examination.

---

## 2. Purpose

This guide is designed to help examination candidates:

- Access the examination system
- Log in securely
- View available examinations
- Start and navigate an examination
- Answer and review questions
- Submit an examination
- View examination results
- Troubleshoot common issues

---

## 3. Intended Audience

This guide is intended for:

- Students
- Examination candidates
- Users participating in online assessments

No advanced technical knowledge is required to use the system.

---

## 4. System Requirements

Before accessing the system, ensure that you have:

- A desktop computer or laptop
- A stable internet connection
- A supported modern web browser
- Valid login credentials
- JavaScript enabled in the browser

### Recommended Browsers

The system can be accessed using modern versions of:

- Google Chrome
- Microsoft Edge
- Mozilla Firefox

For the best experience, keep your browser updated to the latest available version.

---

## 5. Getting Started

### Step 1: Open the Application

Open a supported web browser and navigate to the Online Examination System.

### Step 2: Log In

Enter your registered username or email address and password.

Select **Log In** to access your account.

### Step 3: Access the Dashboard

After successful authentication, the system displays your dashboard.

The dashboard provides access to available examinations and other relevant information.

---

## 6. Dashboard Overview

The dashboard may contain the following sections:

| Section | Description |
|---|---|
| Available Exams | Displays examinations assigned to the user |
| Upcoming Exams | Shows examinations that have not yet started |
| Completed Exams | Displays previously completed examinations |
| Results | Provides access to available examination results |
| Profile | Contains the user's account information |

---

## 7. Starting an Examination

To start an examination:

1. Open the **Available Exams** section.
2. Select the examination you want to take.
3. Review the examination details.
4. Read the examination instructions carefully.
5. Select **Start Exam**.

Once the examination begins, the examination timer may start automatically.

> **Important:** Make sure you are ready before selecting **Start Exam**. Depending on the examination configuration, you may not be able to restart the attempt.

---

## 8. Answering Questions

During the examination, questions are displayed on the examination screen.

Depending on the question type, you may need to:

- Select one answer from multiple choices.
- Select multiple answers.
- Enter a text response.
- Enter a numerical answer.

After answering a question, select **Next** to continue.

---

## 9. Navigating Between Questions

The examination interface may provide navigation controls that allow you to move between questions.

Common navigation options include:

- **Previous** — Returns to the previous question.
- **Next** — Moves to the next question.
- **Question Number** — Opens a specific question.
- **Review** — Allows you to identify questions that require additional review.

Review your answers before submitting the examination.

---

## 10. Managing the Examination Timer

If the examination has a time limit, the remaining time is displayed on the examination screen.

Keep track of the timer while answering questions.

### When the Timer Expires

Depending on the examination configuration, the system may:

- Automatically submit your examination, or
- Prevent further responses and submit the saved answers.

Do not wait until the final seconds to submit manually.

---

## 11. Reviewing Answers

Before submitting the examination:

1. Review the question navigation panel.
2. Identify unanswered questions.
3. Review questions marked for later review.
4. Check your selected answers.
5. Make any necessary changes.

Once you are satisfied with your responses, proceed to submission.

---

## 12. Submitting the Examination

To submit your examination:

1. Select **Submit Exam**.
2. Review the confirmation message.
3. Confirm that you want to submit your responses.
4. Wait for the submission confirmation.

> **Warning:** After submission, you may not be able to modify your answers.

Do not close the browser until the system confirms that your examination has been submitted successfully.

---

## 13. Viewing Results

If results are available immediately:

1. Open the **Results** section from the dashboard.
2. Select the completed examination.
3. Review the displayed score and result information.

Depending on the examination settings, detailed answers or feedback may or may not be available.

---

# 14. Troubleshooting

## Issue: Unable to Log In

### Possible Causes

- Incorrect username or password
- Internet connectivity issue
- Account not activated
- Browser-related issue

### Resolution

1. Verify your login credentials.
2. Check your internet connection.
3. Refresh the login page.
4. Try using a supported browser.
5. Contact the system administrator if the issue persists.

---

## Issue: Examination Page Is Not Loading

### Possible Causes

- Slow or unstable internet connection
- Browser cache issue
- Temporary server issue

### Resolution

1. Check your internet connection.
2. Refresh the page.
3. Clear your browser cache.
4. Reopen the examination system.
5. Contact the administrator if the problem continues.

---

## Issue: Examination Was Disconnected

If your internet connection is interrupted during an examination:

1. Check your internet connection.
2. Reconnect to the network.
3. Return to the examination system.
4. Check whether your previous responses were saved.
5. Continue the examination if access is restored.

> **Note:** The ability to resume an examination depends on the system configuration.

---

## Issue: Examination Was Submitted Unexpectedly

If the examination was submitted unexpectedly:

1. Check whether the examination timer expired.
2. Check the examination status from your dashboard.
3. Contact the examination administrator if you believe the submission occurred incorrectly.

---

# 15. Frequently Asked Questions

### Can I change an answer after selecting it?

Yes. If the examination is still active, you can return to the question and modify your answer, subject to the examination rules.

### Can I pause the examination?

This depends on the examination configuration. Some examinations may not allow users to pause once the attempt has started.

### What happens if my internet connection fails?

Reconnect to the internet and return to the examination system as soon as possible. Whether you can resume depends on the system configuration.

### Can I access the examination from a mobile phone?

Mobile access depends on whether the examination system supports mobile devices. A desktop or laptop is recommended unless mobile access is explicitly supported.

### What should I do if I experience a technical problem?

Record the issue and contact the examination administrator or technical support team as soon as possible.

---

# 16. Best Practices

For a smooth examination experience:

- Test your internet connection before starting.
- Use a supported and updated browser.
- Read all examination instructions carefully.
- Keep track of the remaining time.
- Save or review answers when possible.
- Review unanswered questions before submission.
- Do not close the browser until submission is confirmed.
- Contact support promptly if a technical problem occurs.
